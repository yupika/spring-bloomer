# Spring Bloomer ～ 野の花の庭

野の花、雑草の擬人化を題材にした陣取りせりカードゲームの試作版（HTML単一ファイル）。

> 踏まれても踏まれても…いや、踏まれたら踏まれただけ強くなる。
> 同じ花がいっぱい出ると強い、雑草魂のせりゲー。

## 遊び方

`index.html` をブラウザで開くだけ。サーバ不要。

1. 人数（2〜5人）を選ぶ
2. あなたはプレイヤー1。残りはCPU
3. 毎バトル開始時に手札6枚に補充。同時出し→入札の流れで得点カードを取り合う
4. 同スート3枚 or 異4種揃えで即勝、または規定バトル終了時の合計点で勝利

詳しいルールは [`origin-rule.md`](./origin-rule.md) を参照。

## 主な機能

- **スマホ向けタブ式UI**（プレイヤー / バトル / ログ / ルール）
- **CPU性格6種** × **リソース管理3種** × **競り方4種** ＋ジッタで毎回違う相手と対戦
- **テストプレイ機能**：CPUだけで50〜500回回し、性格別勝率・即勝率などを集計

## CPU性格

| 性格 | 行動 |
|---|---|
| バランス | 広く普通に競る |
| 点数狙い | 高得点カードに集中 |
| 色集め | 特定スートを集める |
| コスパ | 安いときだけ参戦 |
| 攻撃的 | 高得点目的を選んで一発で取る |
| 反応型 | 早く取れた色に乗っかる |

各性格は **使い切 / 柔軟 / 保持** のリソース管理スタイルとも組み合わさります。

詳しい挙動とパラメータは [`バランス調整ログ.md`](./バランス調整ログ.md) を参照。
